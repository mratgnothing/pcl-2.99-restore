Plain Craft Launcher (PCL) 本地功能恢复补丁 1.0.0
适用于指定构建的 PCL 2.99.0.0 / Windows

原作者：龙腾猫跃
作者赞助：https://meloong.com/afd/a/LTCat
官方项目：https://github.com/Meloong-Git/PCL
本补丁由第三方独立制作，与官方无隶属或背书关系。

【它能修复什么】
恢复指定 2.99 原版被关闭的游戏版本列表、下载安装、整合包安装入口和版本修改页的 Minecraft 卡片，并显示第三方标识。实际验证覆盖 Minecraft 1.20.1 安装与最小 Modrinth 整合包安装。

这不是“所有 Minecraft 故障通用修复”。Java 版本、显卡驱动、模组冲突和损坏存档需要另行诊断。没有携带任何人的 Java 绝对路径、游戏目录、账号或存档；也不附带 Minecraft 游戏文件。

【运行要求】
Windows 10/11，.NET Framework 4.8，可写的本地 NTFS 目录。支持 32/64 位进程环境，但当前仅在本机 Windows 11 验证；其他电脑兼容性尚需反馈。
需要本机已有原版 2.99.0.0 程序。此工具不是无需原版的完整启动器分发包。

【使用方法】
1. 将分享压缩包完整解压到本地文件夹。
2. 正常退出 PCL。双击 PCLRestoreSetup.exe，无需 Python、Visual Studio 或管理员权限。
3. 选择自己电脑上的 PCL 程序 EXE，点击“校验文件”。
4. 可选：如果启动器误选了空目录，选择实际包含 versions 子目录的 Minecraft 根目录；留空则不改这一设置。
5. 默认将普通自动更新改为仅提示重大漏洞更新，避免覆盖本地补丁；可取消勾选。
6. 阅读说明后勾选确认，点击“备份并修复”。完成后自行打开原来的 PCL。
如果缺少原版，应从官方渠道获取。官方发行页：https://github.com/Meloong-Git/PCL/releases/tag/2.99.0.0 。发行附件或镜像实际内容可能不同，以文件校验为准。

【备份与回退】
原程序和需要改动的 Setup.ini 会备份到所选程序旁边的 PCL\LocalRestoreBackups\时间-随机标记\，并保存事务回执 receipt.xml。备份仅存于接收者本机，可能包含其原有设置，请勿随意公开上传备份目录。
再次打开本安装包，选择同一个程序并点击“恢复原版”。游戏、模组、存档和账号资料不会被删除。若 Setup.ini 在安装后又被修改，回退保留该文件的当前内容，不覆盖后续设置。
未知版本、被占用文件、结果哈希错误会拒绝操作。安装写入失败时会尝试回退；断电或被系统强制终止后，可重新运行“恢复原版”。若提示回退未完成，请保留原版备份，不要删除它。

【范围与更新】
安装器只修改选中的 EXE，以及用户明确选择调整的 PCL\Setup.ini 两项设置。不会搜索整块硬盘，不会自动启动游戏，不会强制结束 PCL，不写账号注册表，不上传信息，不设置后台服务。
手动更新官方版仍可能覆盖补丁；新版本需要重新检查和适配。没有对下载服务未来可用性作保证。
安装包未购买代码签名证书；无法保证所有杀毒软件或 SmartScreen 都不会提示。出现告警时不要关闭安全软件，应核对来源、哈希与源码。
